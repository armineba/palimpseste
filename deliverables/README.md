# Archives présentes

Les deux ZIP de ce dossier datent de la passe précédente. Ils ne contiennent
pas le nouveau parcours joueur avec invitation et affichage de la description A.
Ne les distribuez pas comme version actuelle.

Le dernier Player Windows x64 IL2CPP construit sur ce PC se trouve dans
`game/Build/WindowsPlayerFlowOwnerFinal/` à la racine du dépôt. Copier tout le dossier
du Player, sauf le dossier de sauvegarde Unity
`Palimpseste_BackUpThisFolder_ButDontShipItWithYourGame`, pour le tester.
Le SHA-256 de `Palimpseste.exe` et les essais réellement effectués sont consignés
dans `docs/UNITY_TEST_PROOF.md`.

La création du ZIP actualisé a été refusée avant exécution par la revue
automatique de l'outil (`blocked by policy`, sans motif détaillé). Aucun ZIP
actualisé n'est revendiqué.
