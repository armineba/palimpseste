Le catalogue source contient maintenant **141 recettes de sorts distinctes**, composées des **24 effets primitifs** intégrés au Player Windows ci-dessous. Le smoke Core a validé et compilé les **705 couples recette/porteur** ; les contrats ont passé **61/61**. Voir [la bibliothèque](../docs/EFFECT_LIBRARY.md) et [l'état courant](../docs/IMPLEMENTATION_STATUS.md).

Cette archive est **réservée à l'opérateur** : ses scripts d'administration doivent rester hors d'accès du compte worker. Son installation sur un autre PC et l'ouverture à des joueurs externes ne sont pas testées.

Le dossier jouable actuel est [WindowsEffectLibraryPlayable](../game/Build/WindowsEffectLibraryPlayable/Palimpseste.exe) : conserver ensemble ses 29 fichiers. Unity 6000.3.24f1 a terminé le build Windows IL2CPP/URP avec `PALIMPSESTE_BUILD_OK`. Il permet de dessiner plusieurs traits, de terminer le dessin avec un bouton, de lire la description Astra et d'ouvrir le sort compilé dans le laboratoire. Le compilateur et le runtime disposent de 24 effets contrôlés et de signaux VFX associés ; les 6 tests PlayMode ciblés passent. Le sort « Enclume filante » est prêt après reprise de la même capture. Le nouveau VFX n'a pas encore été inspecté visuellement par le créateur.

La génération demande le service privé API + worker sur cette machine. Le worker exécute `codex exec` sous le compte Windows isolé `PalRuntimeSvc` : Astra reçoit l'image, Luna prépare un plan de sort déclaratif, puis le compilateur serveur le vérifie. Aucun jeton Codex, secret de base ou clé API n'est livré dans le Player. Les scripts d'administration et l'archive backend sont réservés à l'opérateur ; le worker joueur ne peut pas lancer un build Unity ou modifier le code du projet. Le laboratoire actuel utilise `127.0.0.1` ; aucun accès HTTPS public n'est livré.

Pour reprendre l'essai privé, suivre [TESTER_MAINTENANT.md](../docs/TESTER_MAINTENANT.md) et les états exacts dans [IMPLEMENTATION_STATUS.md](../docs/IMPLEMENTATION_STATUS.md).
