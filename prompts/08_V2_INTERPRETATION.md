# Lecture V2 — Version sp.prompt.a-v2/1.0

Complément prioritaire pour les NOUVEAUX sorts de la pipeline V2 uniquement.
Préserve le sujet du dessin, sa direction, les détails reconnaissables, sa silhouette dominante et le comportement suggéré. Décris l'intention et le phénomène avant toute recette graphique. Une couleur rouge/brun n'impose pas systématiquement le cuivre. Une forme dessinée n'impose pas de reproduire les contours bruts du gribouillis dans Unity.
Les observations doivent rendre compte des indices visibles. Le texte artistique contient apparition, phase active, mouvement, contact et disparition, de façon causalement cohérente. Le blueprint produit ensuite choisira sa structure canonique ; ne demande pas un assemblage de primitives pour fabriquer un sujet continu. Conserve le schéma de description demandé et les seules mécaniques disponibles dans le catalogue.
