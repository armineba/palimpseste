# Schémas de sortie pour l'adaptateur Codex

Ces fichiers sont extraits de la propriété `schema` des enveloppes `model-a.response-format.json` et `model-b.response-format.json` du dossier SP-1.0. Ils ne contiennent pas l'enveloppe Responses.

Ils sont des schémas documentaires destinés au préflight de `codex exec --output-schema`. Une validation JSON Schema locale ne prouve pas leur acceptation par Luna ou le transport installé. Adapter le sous-ensemble de transport si nécessaire, sans affaiblir la validation métier locale. Aucun appel réel n'est livré ici.
